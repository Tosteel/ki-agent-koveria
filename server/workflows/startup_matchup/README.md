# Startup Matchup Workflow

Dieser Workflow identifiziert potenzielle Startup-Kooperationspartner fuer etablierte Unternehmen.

## Ziele
- strategisch passende Startups systematisch finden
- Marktsondierung beschleunigen
- priorisierte Shortlist mit Relevanzbewertung erzeugen
- Abschlussbericht als JSON und PDF bereitstellen

## Step-Kette
1. workshop_analysis
2. company_profile
3. gap_analysis
4. startup_search
5. startup_structuring (step 4.1)
6. startup_ranking
7. startup_deep_research
8. startup_profiles
9. final_report
10. pdf_report

Details und Beispielaufrufe: `process_startup_matchup_v0_1.md`
